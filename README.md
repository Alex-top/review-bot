# Бот для сбора отзывов с интеграцией с Яндекс.Диском

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue)](https://www.python.org/)
[![VK API](https://img.shields.io/badge/VK%20API-5.199-blue)](https://dev.vk.com/)
[![Yandex Disk API](https://img.shields.io/badge/Yandex%20Disk%20API-1.0-blue)](https://yandex.ru/dev/disk/)

Бот для ВКонтакте, который собирает отзывы и оценки пользователей, автоматически синхронизируя их с Яндекс.Диском.

## 📋 Функционал

### Для пользователей (в VK)
- **Оставить отзыв** — оценка от 1 до 5 + текстовый отзыв
- **Мои отзывы** — просмотр своих отзывов
- **Статистика** — общая статистика по отзывам
- **Удобные кнопки** — весь процесс без команд

### Для администратора
- Все отзывы автоматически сохраняются в Яндекс.Документах
- Файл `reviews.csv` синхронизируется при каждом новом отзыве
- Можно открыть таблицу в Яндекс.Документах и работать с данными

### Технические особенности
- 🔘 **Клавиатуры и callback-кнопки** для всех действий
- ☁️ **Интеграция с Яндекс.Диском** для хранения данных
- 📊 **Статистика** в реальном времени
- 🧠 **Ядро** и **адаптер** — архитектура для любой платформы

## 📦 Структура данных

Отзывы хранятся в `reviews.csv` с полями:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INT | Уникальный номер |
| `user_id` | INT | ID пользователя VK |
| `user_name` | STR | Имя пользователя |
| `rating` | INT | Оценка 1–5 |
| `text` | STR | Текст отзыва |
| `date` | DATETIME | Дата создания |
| `status` | STR | `new` / `processed` / `archived` |

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш-аккаунт/review-bot.git
cd review-bot

Создание и активация виртуального окружения
python -m venv review_env
source review_env/bin/activate        # Linux/Mac
review_env\Scripts\activate           # Windows

Установка зависимостей
pip install -r requirements.txt

Настройка окружения
Создайте файл .env в корне проекта:
VK_TOKEN=ваш_токен_сообщества
VK_GROUP_ID=123456789
YANDEX_TOKEN=ваш_oauth_токен_яндекса

Как получить токены:

VK_TOKEN: Управление сообществом → Работа с API → Создать ключ (права: «Сообщения сообщества», «Управление сообществом»)

YANDEX_TOKEN: Яндекс.Полигон → Получить токен

Запуск в консоли (для тестирования)
python scripts/console_runner.py

 Запуск в VK
 python adapters/vk.py
